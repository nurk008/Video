# Сценарий Выпуска №4: «Зимний капкан Улытау (1510): как Касым-хан сокрушил непобедимого завоевателя без единого генерального боя» (RU / KZ / EN)

> **Стандарт продакшна (`GEMINI.md` + `hanafi_ai_content_rules.md`):**
> * Подача: захватывающий военно-исторический триллер (как и за счёт какой стратегии победили в 1510 году; никаких религиозных проповедей вслух, 100% уважительная историческая точность *Сидк* по источникам *Тарих-и Рашиди* и *Бабур-наме*).
