# Передача эстафеты между аккаунтами (`/sync-handoff`)

Выполни перед завершением крупного этапа или перед переходом пользователя на другой аккаунт:

## 1. Проверка порядка в файлах
1. Убедись, что все созданные скрипты, сценарии, кадры и готовые ролики лежат строго внутри репозитория `Video` (ничего не оставлено в `/tmp` или вне проекта).
2. Если в этом сеансе собирались новые видео в `output/`, проверь их размер и параметры:
   ```bash
   ls -lh output/*.mp4
   ```
   и для новых файлов сними точную длительность, разрешение и fps через `ffprobe`.

## 2. Обновление `PROJECT_STATUS.md`
Добавь или обнови блок по текущему этапу/выпуску в `PROJECT_STATUS.md`:
* Дата последнего обновления.
* Что именно сделано (ссылки на сценарий, сборочный скрипт в `production/`, итоговый `.mp4` в `output/` с длительностью и размером).
* Чёткий пункт **«Следующий шаг»**, чтобы следующий аккаунт стартовал с полуслова и без лишнего чтения старых файлов.

## 3. Синхронизация с GitHub (`origin/main`)
Выполни проверку и отправку изменений:
```bash
git status -s
git add -A
git commit -m "Sync progress: <краткое описание этапа>"
git push origin main
```
* Если `git push` не прошёл (нет прав, конфликт или слишком большой бинарник), **не оставляй это молча** — покажи точную причину и команду, которую нужно выполнить локально.
* В конце дай краткую сводку в 3–5 строк: что сохранено в GitHub и с чего начинать следующему аккаунту.
