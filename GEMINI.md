# GEMINI.md — Единая база и правила синхронизации проекта «Video»

> **ВНИМАНИЕ АГЕНТУ:** Пользователь работает над этим проектом с нескольких аккаунтов по очереди (переключается при исчерпании квот). Этот репозиторий — **единая общая база**. Экономь контекст и квоту!

## 1. Обязательный протокол при старте любого чата (быстрый и экономный)
1. **Синхронизация Git:**
   ```bash
   git pull --rebase origin main 2>/dev/null || true
   ```
2. **Точка продолжения:** прочитай **только** `PROJECT_STATUS.md`, чтобы знать текущий статус и не перегружать контекст.
3. **Не читай заранее** тяжёлые справочники (`hanafi_ai_content_rules.md`, `ai_history_channel_guide_and_history.md`, `kazakh_history_chat.md`, старые сценарии `*_viral_script.md`), если текущая задача их не требует. Для сценариев, кода сборки и публикации работают модульные правила в `.agents/rules/` и слэш-команды из `.agents/skills/`.

## 2. Негласные константы проекта (всегда в силе)
* **Язык с Выпуска №4 (`EP04+`):** собираем и публикуем **только казахскую версию (`KZ`)**, если пользователь явно не попросил RU/EN.
* **Подача и смысл:** исторический триллер/документалистика **без религиозных проповедей и терминов вслух**, но со строгим соблюдением внутренних норм: 100% достоверность (*Сидк*), только благие качества народа, **запрет** на темы раскола/междоусобиц, предательств и суеверий/шаманизма.
* **Визуал (`9:16`):** строго без детальных лиц крупным планом (силуэты, со спины, детали рук/оружия/карт, всадники вдалеке, панорамы Степи), без крови/жестокости, закрытый аурат, без изображений пророков/ангелов. Жёсткая субпиксельная камера (без `warp` / «желе»).
* **Звук:** студийный TTS (`kk-KZ-DauletNeural`, норма `-14 LUFS`) + физические SFX + вокальный *A cappella* фон, **строго без музыкальных инструментов**.

## 3. Проектные слэш-команды и правила (`.agents/`)
* **Команды (`/`):** `/new-episode` (создание нового выпуска), `/check-halal` (аудит сценария, промптов и сборки), `/sync-handoff` (финализация и передача другому аккаунту).
* **Правила:** `.agents/rules/content-halal-history.md` (сценарии и факты), `.agents/rules/video-pipeline.md` (скрипты сборки в `production/`), `.agents/rules/publish-checklist.md` (чек-лист публикации — подключается автоматически при подготовке к выкладке).
* **Автоопределение:** если пользователь не указал номер выпуска или имя файла, определи текущий/последний выпуск автоматически по `PROJECT_STATUS.md`, `git status -s` и самым новым файлам в `output/` и `production/`.

## 4. Обязательный протокол после каждого завершённого этапа
1. Сохраняй все файлы **только внутри папки проекта `Video`** (не во временных директориях).
2. Обнови `PROJECT_STATUS.md` (что сделано, параметры готовых файлов и следующий шаг).
3. Если подключён Git (`origin`), сразу выполни:
   ```bash
   git add -A && git commit -m "Sync progress" && git push origin main
   ```
